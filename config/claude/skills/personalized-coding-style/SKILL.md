# Personalized coding style

My personalized coding style for all projects.

## Coding Style

- Always follow the S.O.L.I.D. principles. (https://en.wikipedia.org/wiki/SOLID)
- Always make clean method, one method for one change as much as possible.

## How to implement

- Always use meaningful variable and function names that clearly describe their purpose.
- Always run test after editing some code to ensure that the code is working as expected, at least for the part that you have changed.
- Always write unit tests for new features and bug fixes.

## Project management

- One commit per one change.
